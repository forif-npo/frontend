# FORIF Frontend 팀 컨벤션

이 디렉터리는 FORIF Frontend를 함께 개발하는 사람이 따르는 협업 기준입니다. 자동화
에이전트의 작업 지침과는 별개이며, 팀의 합의가 바뀌면 이 문서를 먼저 갱신합니다.

## 읽는 순서

1. 새 팀원은 [온보딩](01-onboarding.md)과 [Git·릴리즈 전략](02-git-branch-release.md)을 읽습니다.
2. 코드를 작성하기 전에는 [코드 컨벤션](05-code-convention.md)과
   [프론트엔드 구조](06-frontend-architecture.md)를 확인합니다.
3. 화면, 테스트, API를 변경할 때는 각각의 전문 컨벤션을 함께 확인합니다.
