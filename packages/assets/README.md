# `@repo/assets`

FORIF 서비스에서 사용하는 아이콘, 이미지, 폰트를 제공하는 공통 에셋 패키지입니다.

## 공개 경로

| 경로                        | 내용                 |
| --------------------------- | -------------------- |
| `@repo/assets/icons/krds`   | KRDS 아이콘 컴포넌트 |
| `@repo/assets/icons/lucide` | Lucide 아이콘 export |
| `@repo/assets/images`       | 이미지 export        |
| `@repo/assets/images/*`     | 개별 이미지 파일     |
| `@repo/assets/fonts/*`      | 폰트 파일            |

새 에셋은 저작권·라이선스·용량을 확인하고, 실제 사용 경로와 함께 추가합니다.
